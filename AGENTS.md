# AGENTS

Este repositorio esta fora da Gestao de Acesso MVP.

Antes de implementar qualquer funcionalidade mobile, crie ou leia uma spec correspondente em `../gestor-master-docs/docs/specs`.

## Regras locais

- Nao implemente funcionalidades sem spec central.
- Nao duplique requisitos neste repositorio.
- Use `../gestor-master-docs` como fonte da verdade.
- Siga `../gestor-master-docs/docs/design/visual-identity.md`, `DESIGN_SYSTEM.md` e `design/tokens.json` para qualquer trabalho visual.
