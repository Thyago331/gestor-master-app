# Design System

Este repositorio deve seguir o padrao visual definido em `../gestor-master-docs/docs/design/visual-identity.md`.

## Uso local

- Tokens compartilhados: `design/tokens.json`.
- Assets de marca: `assets/brand/logo.png` e `assets/brand/logo-transparent.png`.
- O app mobile ainda nao tem stack definida, entao os tokens ficam como contrato de produto ate o scaffold.
- A interface deve manter tema escuro/cafe, metal grafite e acento laranja.
- Detalhes pixel-art devem ser usados com parcimonia em marca, badges, botoes e estados.

## Regra

Se houver divergencia entre este arquivo e `../gestor-master-docs/docs/design/visual-identity.md`, a documentacao central vence.
